# Pomme Android — Public Contribution Guide

This is an unofficial Android-focused continuation/experiment based on Pomme. Please credit the original Pomme project and follow its applicable license and contribution rules.

## Before proposing a change
- Explain the user-facing problem and expected behavior.
- Keep changes focused and avoid unrelated modifications.
- Preserve existing worlds, player data, and user settings.
- Keep local singleplayer behavior separate from authenticated multiplayer.
- Include reproducible steps and tests where practical.
- Clearly distinguish proposed, implemented, and verified work.

## Android considerations
- Prefer mobile-friendly workflows and controls.
- Consider differences between Android versions and device hardware.
- Do not claim broad device compatibility based on a single-device test.

## Security and privacy
Never commit access tokens, passwords, signing keys, private account data, or personal information. Do not weaken multiplayer authentication to simplify local singleplayer access.

## Project status
The public roadmap and user-visible issues are maintained in this repository. Internal engineering documentation is maintained separately and is not part of the public contribution guide.
