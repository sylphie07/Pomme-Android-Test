# Pomme Android — Public Status

Last updated: 2026-10-30

## Current direction
The project is focused on making the Android experience more practical while preserving the original project's identity and online security model.

## User-visible progress
- The menu can be explored without immediately requiring Microsoft sign-in.
- Local singleplayer access has been tested by the project owner on an Android device.
- The project owner reported that a locally created world now opens without an account prompt.

## Known next improvement
World creation currently returns to the world list after the world is created. The expected experience is to enter the new world immediately. This remains a user-facing improvement to investigate and verify.

## Public roadmap
- Direct entry into newly created worlds.
- Better configurable touch controls.
- Continued Android stability and compatibility work.
- Preserve local worlds and keep online authentication requirements for multiplayer.

## Documentation policy
Detailed implementation notes, internal investigations, programmer handoffs, security analysis, and session-by-session development records are maintained in the private companion repository. This public file intentionally contains only a high-level project handoff.
