# Pomme Android — Public Product Decisions

Last updated: 2026-10-30

## Product direction
- Keep this work clearly identified as an unofficial Android-focused fork/experiment.
- Credit and respect the original Pomme project and its developers.
- Allow local singleplayer use without forcing online account sign-in.
- Keep Microsoft/Java authentication for multiplayer and protected online features.
- Prioritize preservation of existing worlds and player data.
- Improve mobile usability, including configurable touch controls.

## Documentation boundary
Public documentation describes project goals, user-visible status, roadmap, and known user-facing issues. Detailed architecture, implementation plans, security reviews, and internal development records belong in the private companion repository.
