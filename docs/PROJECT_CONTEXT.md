# Pomme Android — Public Project Overview

Last updated: 2026-10-30

## About
This repository contains an unofficial Android-focused continuation and experimentation effort based on Pomme. It is not the official Pomme project. Please respect and credit the original Pomme developers and upstream project.

## Project goals
- Improve the usability of Pomme on Android devices.
- Make local singleplayer world creation and play accessible without requiring an online account.
- Keep Microsoft/Java account verification for multiplayer and other protected online features.
- Improve touch interaction and mobile-friendly controls.
- Preserve compatibility with existing worlds and user data.

## Public status
- The Android menu and local singleplayer access have received improvements.
- The user has reported successful entry into a locally created world without a Microsoft sign-in prompt.
- One user-facing flow still needs attention: after creating a world, the app currently returns to the world list instead of automatically entering that new world.
- Further improvements are planned and will be announced here at a high level.

## Roadmap
1. Improve the create-world experience so a newly created world opens directly.
2. Continue improving touch controls and configurable mobile input.
3. Improve stability, compatibility, and usability across Android devices.
4. Keep multiplayer authentication and existing-world compatibility intact.
